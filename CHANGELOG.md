# Изменения

## 1.0.5.1

- #19: внутренние значения по умолчанию применяются к создаваемому элементу и
  не изменяют общий контекст и настройки следующих элементов.
- Добавлены runtime-регрессии для повторного использования контекста,
  пользовательских значений и его состояния после ошибки создания.
