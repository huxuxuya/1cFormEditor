## Требования

- Python 3.9 или новее для скриптов и unit tests.
- Docker для контейнерных проверок.
- Для сборки отдельного .cfe нужна утилита ibcmd платформы 1С.
- Smoke и полный release gate также требуют подходящих компонентов 1С; полный
  gate использует EDT и его плагины. Требования к пакетам и лицензированию
  зависят от запускаемой проверки и описаны в соответствующих инструкциях.

## Python unit tests

Тесты используют стандартную библиотеку Python:

```sh
python3 -m unittest discover -s tests -v
```

## Smoke-проверка в Docker

Чтобы проверить OneScript, Vanessa Runner и Xvfb без установщика платформы 1С:

```sh
./scripts/run-container-smoke.sh --check-toolchain
```

Запуск BDD против готовой инфобазы и подготовка новой инфобазы из EDT export
описаны в [инструкции Docker smoke](../docker/1c-smoke/README.md). Она содержит
требования к пакетам платформы, каталогам и отчётам.

## Сборка отдельного расширения .cfe

Экспортируйте проект FormEditor из EDT в XML формата Конфигуратора и укажите
путь к 1cv8 или ibcmd. Если указан 1cv8, ibcmd должен лежать рядом.

```sh
python3 scripts/build-extension.py \
  --platform "/path/to/1cv8" \
  --source "/path/to/designer-xml-export" \
  --output "build/FormEditor.cfe"
```

Эта команда собирает только расширение .cfe. Скрипт подготавливает XML через
scripts/prepare-extension.py, создаёт временную файловую базу и проверяет
расширение средствами ibcmd. Уже существующий файл результата не
перезаписывается. Для отдельной подготовки XML используйте:

```sh
python3 scripts/prepare-extension.py \
  /path/to/designer-xml-export build/extension-xml
```

## Полный release gate

Запуск контейнерной сборки и проверок:

```sh
./scripts/run-container-release.sh
```

Полный список входных данных, этапов, статусов, baseline и результатов описан в
[документе release gate](release-gate.md).

## Legacy Windows и OneScript runner

`legacy/vanessa/` содержит прежний Windows/OneScript процесс: `Jenkinsfile`,
`run_vanessa.bat`, `config/` и BDD-сценарии. В настройках есть привязки к локальным каталогам и
историческим версиям инструментов; переносимость на другую машину не
предполагается без настройки. Этот процесс не проверялся в текущем окружении.
Перед использованием проверьте пути, версии EDT/платформы и настройки Runner
для целевой Windows-среды. Путь к сценарию задан относительно корня репозитория.
Создайте `.local/vanessa-output/` для отчётов Runner. Внешняя Jenkins job
должна быть настроена на файл `legacy/vanessa/Jenkinsfile`.

Встроенная тестовая обработка запускает зарегистрированные проверки при
открытии основной формы TestForFormModificator. В форме показываются итоги и
протокол проверок; дополнительные формы используются как скрытые сценарии.
Проверка динамического списка подтверждает его создание и очистку свойств
контекста, но не выполнение запроса и получение данных.

Счётчики вызовов на странице «Итоговая таблица» относятся к демонстрации и не
заменяют результаты автотестов. Проверки относятся к зарегистрированному
набору сценариев, а не ко всем возможным условиям работы платформы.
