# Исторические файлы

`edt-root/` сохраняет бывшие корневые EDT `.settings/` и `DT-INF/`. Это
исторические metadata, они не относятся к текущему EDT-проекту `../FormEditor/`
и не используются актуальными scripts/tests.

Старый Windows/OneScript/Vanessa workflow удалён. Текущие команды владельца для
проверок CF/CFE — `../scripts/run-container-tests.sh` и
`../scripts/run-container-tests.sh --manual`; требования и отчёты описаны в
[`../docs/development.md`](../docs/development.md).
